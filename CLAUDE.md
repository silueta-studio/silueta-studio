# Silueta Studio — instructions for Claude Code

This repo makes vertical story videos (1080×1920, 30 fps, 60–130 s): original 2D silhouettes drawn in Python, rim light,
parallax, karaoke captions, real voice-over. Talk to the user in their language; write the video in the language they ask for.

## Rules (never break)
- **Facts:** every claim in a real-story video needs 2 independent sources. Mark FACT vs HYPOTHESIS; drop disputed details.
- **Rights:** no photos, logos, film stills or third-party characters. Everything visual is drawn in code.
  Music and sound effects only from files the user provides and has a licence for. The kit ships none.
- **Money and publishing:** never spend API credits, buy anything or publish/schedule a video without the user's explicit OK for that action.
- Never claim a file was rendered, saved or published without checking it exists.

## Pipeline (one folder per story; `silueta <cmd> -h` for options; on Windows `silueta` also works)
1. Research → `fatos.md` (agent `researcher`).
2. Script by shots S01…Snn → `historia.json` (agent `scriptwriter`). `silueta new <folder>` creates the template.
3. Scenes → `cenas.py`, one `@cena("Snn")` function per shot (agent `scene-designer`). Check with `silueta sheet <folder>` (contact sheet + safe-zone QA) after every change.
4. Voice: one file per shot in `<folder>/voz/` (s01.mp3, s02.mp3…), recorded or generated by the user.
   `silueta align <folder> --python <venv-with-whisperx>` → real timings, karaoke words, `voz.wav`.
5. `silueta mix` (voice + user's licensed music/SFX, ducking, −14 LUFS) → `silueta render` (parallel, resumable) → `silueta qa`.
   Agent `render-qa` runs steps 5 and reports.

## Craft rules (what makes these videos watchable)
- **Hook first:** something moves in frame 0; the threat/question is on screen by 1 s; the first sentence works without context.
- Something new on screen every 2–4 s (camera move, new element, card, cut). One idea per shot, 3–8 s per shot.
- Depth: 3–5 layers (sky, far ridge, mid, subject, dark blurred foreground). Far = lighter; subject between layers; rim light on silhouettes.
- Vary scale: wide, medium, close; at least one extreme close-up per minute.
- Text between y=150 and y=1500, 60 px side margin; captions never cover the subject (`subj` boxes in `@cena`).
- Reading pace ≤ 3.5 words/s per shot; a short pause before the key moment; silence before the big hit.
- Loop ending: the last shot repeats the framing of S01, so the video loops.
- Determinism: random only with a fixed seed (`np.random.default_rng(seed)`), never clocks: parallel render parts must match.

## Scene API (from `silueta_studio import ...`)
`push(tl, z, rate, pan)` camera · `sky(f, key, stops)` · `terr(f, C, par, seed, base, amp, col, peak=…)` returns ridge y(x) ·
`fg(f, C, seed, y, blades)` dark foreground · `disco` sun/moon · `haze` · `rayos` light rays · `brasas`/`chispas` particles ·
`pessoa`, `ave`, `barco`, `put` (RGBA sprite with feet anchor) · `R(f, x0, y0, x1, y1).poly/ell/line/text/rim` region drawing ·
`card(f, text, (x, y), size, tl, t0)` spring-in card · `label` · `fin(f)` finishing grade (call before cards) · `temblor`, `flashk` impacts.
`c["tw"]("word", default)` = local time of a spoken word in the shot: sync cards and hits to the voice.
